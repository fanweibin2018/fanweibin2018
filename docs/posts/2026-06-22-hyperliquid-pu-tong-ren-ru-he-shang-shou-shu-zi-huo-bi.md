# Hyperliquid 是什么，以及一个普通人该如何谨慎地走进数字货币

> 这篇文章想做两件事：把 **Hyperliquid** 这个 2026 年绕不开的名字讲清楚；再把「**一个完全没基础的普通人，该怎么不被割、循序渐进地认识数字货币**」讲明白。
>
> 先把话说在前头——**本文不是劝你入场，更不构成任何投资建议。** 数字货币是高风险资产，价格 24 小时波动、可以归零；而 Hyperliquid 本身是一个**杠杆合约**平台，恰恰是这个领域里最危险的角落。看懂它，和该不该碰它，是两回事。

在进入正文之前，请先把这三句话刻在脑子里。后面所有内容，都建立在它们之上。

## 一、先认识 Hyperliquid：一个「没有公司」的交易所

### 1.1 它想解决的，是一个被 FTX 血淋淋证明过的问题

要理解 Hyperliquid，得先理解它诞生的背景。

数字货币的交易，长期分成两种地方：

- **中心化交易所（CEX）**：比如 Binance、Coinbase、OKX。你把钱充进去，币其实存在**交易所手里**，你看到的余额只是它数据库里的一个数字。体验流畅、速度快，但你必须**信任这家公司**不作恶、不挪用、不跑路。
- **去中心化交易所（DEX）**：交易直接发生在区块链上，钱始终在**你自己的钱包**里，没有中间商托管。但传统 DEX 大多用「自动做市商（AMM）」那套机制，撮合慢、滑点大、做不了专业的合约交易。

2022 年 11 月，全球第二大交易所 **FTX 轰然倒塌**，挪用了上百万用户的资产。那一刻，「**Not your keys, not your coins**（私钥不在你手里，币就不是你的）」从一句口号变成了血的教训。

Hyperliquid 的野心就是：**把 CEX 的丝滑体验，搬到一条任何人都能验证、谁也挪用不了你资产的区块链上。** 既要专业交易者要的速度和深度，又要去中心化的「不用信任任何公司」。

### 1.2 技术上它到底是什么：一条专为交易而生的链

一句话概括：

> **Hyperliquid 是一条自己的 Layer-1 公链，链上跑着一个完全透明的「订单簿」交易所，主打永续合约。**

拆开看几个关键词：

| 名词 | 大白话解释 |
| --- | --- |
| **L1 公链** | 它不是建在以太坊上的应用，而是**自己一条独立的区块链**，叫 HyperCore，专门为交易优化。 |
| **链上订单簿（CLOB）** | 像股票交易所那样的「买一卖一」挂单簿，**完全跑在链上**，没有藏在后台的暗箱撮合。每一笔挂单、成交都写进区块。 |
| **HyperBFT 共识** | 它的「记账规则」，能做到**不到 1 秒最终确认、每秒处理 20 万+ 笔订单**——这是它体验接近 CEX 的底气。 |
| **永续合约（Perps）** | 一种没有交割日的杠杆衍生品，可以做多也可以做空，最高 **50 倍杠杆**。⚠️ 这正是新手的头号雷区，后面专门讲。 |
| **HyperEVM** | 在交易内核之外，又长出一层**兼容以太坊的智能合约环境**，让开发者能像在以太坊上一样部署 DeFi 应用，共享同一套安全性。 |

用一张图看清「你的钱在谁手里」这件最要命的事：

```
        中心化交易所 CEX              Hyperliquid（链上）
        ─────────────                ─────────────────
                                     
          你                             你
          │ 充值                         │ 连接自托管钱包
          ▼                             ▼
     ┌──────────┐                  ┌──────────────┐
     │ 交易所的  │  ◄── 钱在它手里   │  你自己的     │  ◄── 钱始终
     │ 钱包/账本 │      （信任它）   │  链上钱包     │      在你手里
     └──────────┘                  └──────┬───────┘
          │                               │ 链上撮合，全程可查
          ▼                               ▼
      它说你有多少                    区块链说你有多少
      就有多少                        谁也改不了、挪不动
```

### 1.3 「无 VC 空投」：HYPE 代币的故事

Hyperliquid 还有一件让它在圈内封神的事：**它的代币 HYPE，几乎全靠用户「自己人」起家。**

2024 年 11 月，Hyperliquid 发行原生代币 HYPE，做了一次**史上最慷慨的空投之一**：

- 把约 **3.1 亿枚 HYPE**（占总量约 **31%**，按当时价格约合 **12 亿美元**）直接空投给了 9 万多名早期真实用户；
- **没有拿任何风险投资（VC）的钱**，没有给机构留份额。

这在「VC 低价进场、散户高位接盘」已成行业潜规则的当下，是一种近乎叛逆的姿态——把利益更多地留给了真实使用产品的人。这份「无 VC、社区优先」的叙事，是 HYPE 后来能聚起强大共识的重要原因。

> 当然，**「叙事好」不等于「价格只涨不跌」。** 代币价格依然剧烈波动，HYPE 也不例外。别把情怀当成买入理由。

### 1.4 它现在有多大

到 2026 年，Hyperliquid 已经是**永续合约 DEX 里当之无愧的老大**：

- 占据整个永续合约 DEX 市场约 **32%～44%** 的交易量份额；
- 近 30 天合约交易量级达到 **千亿美元** 量级，未平仓合约（OI）超过 **90 亿美元**；
- 总锁仓价值（TVL）约 **40～60 亿美元**，累计用户约 **140 万**；
- 还在往外扩：HIP-3 让人能自建市场，HIP-4 上线了预测市场，甚至开始做大宗商品、股指等「真实世界资产（RWA）」的永续合约——一个 7×24 小时、什么都能交易的「全品类衍生品平台」雏形已现。

### 1.5 一堂价值千金的风险课：JELLY 事件

讲 Hyperliquid，**绝不能只讲它的光鲜**。2025 年 3 月那场 **JELLY 事件**，是每个想了解它的人都该读的一课。

事情大致是这样：

```
  攻击者          ① 在 Hyperliquid 上对一个叫 JELLY 的土狗币
   │                开了巨额「空单」，同时在现货市场猛买 JELLY
   ▼
 现货价格被拉高 ──► ② 空单巨亏被强制平仓，这个「烂摊子」
   │                按机制甩给了平台的做市金库 HLP
   ▼
 继续拉盘       ──► ③ HLP 浮亏一度高达 1350 万美元，
   │                而整个金库才约 2.9 亿——有被击穿的风险
   ▼
 平台介入       ──► ④ 验证者们 2 分钟内「全票通过」，直接
                     无视市场价、把 JELLY 强制按开仓价结算并下架
```

结果是：HLP 金库保住了，没被击穿；但代价是——**一个号称「去中心化」的平台，在关键时刻由少数验证者投票，人为篡改了价格、动了本该由代码自动执行的规则。**

这件事在圈内炸开了锅。有交易所 CEO 公开开炮，说这让人想起「FTX 2.0」，批评它「不成熟、不专业」。Hyperliquid 事后也改进了自动减仓（ADL）的触发机制。

它给所有人的教训是双重的：

> - **对市场**：再「去中心化」的系统，遇到生死关头，也可能有「人治」介入。「Code is law（代码即法律）」在极端情况下会打折扣。
> - **对新手**：连机构级玩家、连平台自己都会在土狗币和杠杆里翻车，**你凭什么觉得自己能全身而退？**

记住这堂课。下面我们回到地面。

## 二、回到地面：普通人的数字货币「认知地图」

很多人对数字货币的全部认知就是「比特币、暴富、骗局」。要安全上手，得先把基础概念铺平。这一节不教你买，只帮你**看懂**。

### 2.1 先把几个词搞懂

| 概念 | 一句话理解 | 给新手的提醒 |
| --- | --- | --- |
| **比特币 BTC** | 第一个、也是共识最强的数字货币，常被叫「数字黄金」。 | 波动依然巨大，不是「稳赚」。 |
| **以太坊 ETH** | 一台「世界计算机」，绝大多数 DeFi、应用都建在它上面。 | 用链上应用要付「Gas」给它。 |
| **稳定币 USDT / USDC** | 锚定 1 美元的币，是币圈的「现金」和计价单位。 | 选主流、合规的；小币种「稳定币」可能脱锚。 |
| **钱包 Wallet** | 存放和管理你数字资产的工具，分热钱包（联网）和冷钱包（离线）。 | 钱包不「存」币，币在链上，钱包只管「钥匙」。 |
| **私钥 / 助记词** | 控制资产的**唯一凭证**，通常是 12～24 个英文单词。 | **谁拿到它，谁就拥有你全部的币。** 命根子。 |
| **Gas 费** | 在区块链上做操作要付的「手续费 / 油费」。 | 以太坊主网很贵，Arbitrum 等二层很便宜。 |
| **CEX / DEX** | 中心化交易所 / 去中心化交易所。 | CEX 像银行 App，DEX 要自己管钱包。 |
| **现货 vs 合约** | 现货=一手交钱一手交货、真买币；合约=带杠杆的「对赌」。 | **新手只碰现货，远离合约。** |

### 2.2 一张图看懂「你的钱会流经哪里」

```
   你的法币（人民币/美元）
        │
        │  ❶ 出入金（须合规！受当地法律约束）
        ▼
  ┌───────────────┐     ❷ 在 CEX 内买卖
  │ 中心化交易所   │ ───────────────► 现货：BTC / ETH / 稳定币
  │   （CEX）      │                  （新手的主战场）
  └───────┬───────┘
          │  ❸ 提现到自己的钱包（自我托管）
          ▼
  ┌───────────────┐
  │ 你的链上钱包    │ ───► ❹ 进阶：链上 DeFi / Hyperliquid 等
  │ (自托管/冷钱包) │       （深水区，懂了再说）
  └───────────────┘
```

绝大多数普通人的活动，应该**长期停留在 ❶❷ 两步**：用合规渠道、在主流平台、买主流币的现货。❸❹ 是进阶世界，**先有能力管好自己的钥匙，再谈往里走。**

## 三、小白上手路线图：从最安全的地方起步

下面这条路，刻意设计成「**越往后越危险，每一步都要先通过前一步**」。不要跳级。

```
  Lv.0 调整预期 ─► Lv.1 只学不投 ─► Lv.2 合规出入金 ─► Lv.3 现货+稳定币
                                                          │
       绝大多数人，待在这里就够了 ◄───────────────────────┘
                                                          │
                          （可选，且非必须）              ▼
                    Lv.4 学会自托管与安全 ─► Lv.5 谨慎了解链上/DeFi
```

### 第 0 步 · 调整预期：先做好「亏光」的心理建设

- **它不是提款机。** 你看到的暴富故事，背后是无数沉默的归零者。
- **给自己定一个上限**：拿出总资产中一个就算全亏也不心疼的小比例（很多人会说 1%～5%），把它当成「学费」。
- **接受波动**：一天涨跌 10%～20% 是家常便饭。如果这会让你睡不着、影响工作，说明仓位太重了。

### 第 1 步 · 只学不投：先花一两周「空手」学习

真正的老手，都是先看懂规则才下场的。这一步**一分钱都别花**：

- 读懂上面第二节的所有概念；
- 去主流平台的「学习中心」、维基百科、可信的科普内容，搞懂 BTC、ETH、稳定币的基本逻辑；
- 学会辨认骗局的样子（见第五节）。

### 第 2 步 · 合规出入金：在法律框架内解决「钱怎么进出」

> ⚠️ **这是最需要谨慎、也最受地域法律影响的一步。**

不同国家和地区，对数字货币的买卖、兑换、出入金有**完全不同的法律规定**。中国大陆对加密货币交易及相关业务有明确限制。**请务必先了解并严格遵守你所在司法管辖区的法律法规**，本文无法、也不会替代法律意见。

通用原则（在合规前提下）：

- 选择**信誉好、运营时间长、合规程度高**的主流平台，别贪图来路不明的小平台。
- 完成必要的实名认证（KYC），这通常是合规平台的要求，也是一道安全防线。
- **小额先试一次完整的「入金 → 买 → 卖 → 出金」闭环**，跑通流程、确认能顺利提出来，再考虑加量。

### 第 3 步 · 从「现货 + 稳定币」开始：最朴素，也最稳妥

这是新手**唯一**推荐的主战场：

- **只买主流币的现货**：BTC、ETH 这种共识最强的，而不是各种叫不上名字的「百倍币」。
- **善用稳定币**：把不交易的资金换成 USDT/USDC「现金」拿着，心态会稳很多。
- **考虑定投而非梭哈**：分批、定期买入，平滑掉「买在最高点」的运气成分。这正好呼应仓位管理的智慧——[关于「该押多少」，可以读读我之前写的凯利公式](/posts/2026-05-28-kai-li-gong-shi-cong-xin-xi-lun-dao-tou-zi-de-zi-jin-guan-li)。
- **永远不碰**：合约、杠杆、土狗 meme 币、「保本高息理财」、「带单老师」。

### 第 4 步（可选）· 学会自我托管：把钥匙真正握在手里

当你的资产开始有点分量，可以学着把币从交易所提到**自己的钱包**，实践那句「Not your keys, not your coins」：

- 用主流的自托管钱包（如 MetaMask、Rabby 等 EVM 钱包，或硬件冷钱包）；
- **把助记词抄在纸上，离线保管，多处备份**——这是这一步真正的核心，比买什么币重要一百倍；
- 先小额转一笔，熟悉「转账 → 上链 → 到账」的全过程。

### 第 5 步（进阶，非必须）· 谨慎了解链上世界

只有当你**完全能独立管好钱包和安全**之后，才谈得上去碰链上的 DeFi、跨链桥、乃至 Hyperliquid 这类平台。对绝大多数普通人来说，**走到第三步就已经够了。**

## 四、那 Hyperliquid 呢？新手到底该不该碰？

兜了一圈，回到开头那个名字。一个诚实的回答是：

> **作为「了解对象」，Hyperliquid 很值得看懂；作为「新手的起点」，它几乎是最糟糕的选择。**

原因很简单：Hyperliquid 的核心业务是**永续合约**，是带**最高 50 倍杠杆**的衍生品交易。我们来算一笔账，看看 50 倍杠杆对新手意味着什么：

```
   你有 100 USDC，开 50 倍杠杆 = 操作 5000 USDC 的仓位
        │
        ▼
   行情只要朝你相反方向波动约 2%
        │
        ▼
   5000 × 2% = 100 USDC  →  你的本金全部亏完，爆仓清零
```

**仅仅 2% 的反向波动，就足以让你血本无归。** 而前面说过，币价一天波动 10%～20% 稀松平常。这意味着在 50 倍杠杆下，新手的爆仓几乎是**时间问题**，而不是「会不会」的问题。再加上 JELLY 事件那样的极端行情和插针，杠杆就是一台高效的「本金粉碎机」。

如果有一天，你**真的**已经：用现货稳定盈亏过、完全理解了杠杆和清算机制、能熟练管理自托管钱包、并且做好了「这笔钱归零」的准备——那么，把 Hyperliquid 当成一个「了解去中心化衍生品」的实验场时，请把风险压到最低：

- 用**极小、亏得起**的金额；
- **不用、或只用极低杠杆**（1～2 倍，甚至纯现货思路）；
- 只碰你**真正看得懂**的主流币种，远离土狗；
- **永远不 all in，永远预设最坏结果。**

它的上手流程本身很简单（无需注册和 KYC、连接自托管钱包、从 Arbitrum 跨入 USDC、链上交易甚至不花 Gas）——**但「上手容易」恰恰是它的危险所在**：它把一件极其危险的事，做得像呼吸一样顺滑。

## 五、新手防割清单：这些坑，几乎人人踩过

把这一节当成一份「出门前的安全检查表」。

| 雷区 | 真实样子 | 如何避开 |

| **助记词泄露** | 「客服 / 空投 / 验证」要你输入或截图助记词。 | 助记词只在初始化钱包时用，**任何人问都是骗子**。离线、手抄、永不联网。 |

## 六、给普通人的几条「无聊但有用」的原则

最后，把这篇长文收束成几句你可以随时翻出来看的话：

1. **先合规，再谈一切。** 法律红线之内行事，是底线，不是选项。
2. **只用闲钱，默认归零。** 影响生活的钱，一分都不该进来。
3. **慢就是快。** 看不懂的，不碰；想清楚再动，是优势不是怯懦。
4. **现货是练习场，杠杆是绞肉机。** 新手与合约杠杆之间，应该隔着一堵墙。
5. **私钥即一切。** 守住助记词，胜过追逐任何一个百倍币。
6. **没有人会让你白白赚钱。** 所有「稳赚」「带你飞」，背后想赚的都是你的本金。

>
> 但理解一项技术，和把身家押上去，是两件完全不同的事。**愿你既有看懂世界的好奇，也有守住钱包的清醒。**
